## Several tasks

- List each task's dependencies and mark which ones can run at the same time.
- Don't split frontend and backend into separate tasks when one small
  end-to-end slice is clearer.
- Every requirement needs an owner task and evidence. Every task needs a reason
  to exist.
- A simple ordered table is enough; don't build a scheduling tool.
- These files are the plan. Copy tasks to Jira only if the user asks.
