# Citations

Apply these rules to each fact from a web search, a web page, docs or a file.

## Format

```
<claim> — > "<exact short quote>" ([<source title>](<URL>))
<claim> — > "<exact short quote>" (`path/to/file:line`)
```

## Rules

1. Copy the quote from the text that you fetched or read in this session. Done when you can point to the tool result that holds it.
2. Keep each quote below approximately 25 words. Done when the quote shows only the proof.
3. Prefer primary sources: official docs, the vendor's own page, the repository. Done when each blog source has a reason to be there.
4. If two sources disagree, show both claims, each with its quote. Done when the reader sees the conflict.
5. If no source supports a claim, remove the claim or mark it **[unverified]**. Done when no claim is a guess.

Reason: a quote from memory can be wrong. A quote copied from a fetched page can be checked.

## Sources list

End each research reply with this list:

```
**Sources**
- [<title>](<URL>) — fetched <YYYY-MM-DD>
```
