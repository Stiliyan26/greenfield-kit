# Reply templates

Use these structures. Change the words, not the order.

## Quick answer

For a question. No footer.

```
**<the answer in one sentence>**
- <why / key fact>
- <why / key fact>
Next: <one line, only if there is a useful next step>
```

## Task done

```
**Done: <what now works, one sentence>**
| File | Change |
|---|---|
Cleanup: <what I removed, one line>
Your move: <what you need to do, or "nothing">
```

The checks go in the Evidence footer, not in the body.

## Options and recommendation

```
**Go with <X>** — <one-line reason>
| Option | Good | Bad |
|---|---|---|
```

## Problem or blocker

```
**⚠️ <what's wrong, one sentence>**
- Cause: <one line>
- Fix: <one line>
- Need from you: <one line, or "nothing">
```
